# Native replay and observation adapter

First implementation is assigned to S2–S3 in [DEVELOPMENT.md](../../docs/dev/DEVELOPMENT.md). Build a thin native component against the pinned OCUDU grid interfaces. Reuse the legal stimulus, scheduling and production receiver. Hand off a completed grid and a bounded owned pilot snapshot; distinguish producer completion, consumer completion and buffer release. This directory will contain only the adapter and its build wiring. The initial executable Python fixture in `src/` supplies small input/output reference vectors for native tests. Subdirectories arrive with their tickets: `fixtures/` (S2.1), `replay/` (S2.3), `receiver/` (S2.4), `observer/` (S3.1, S5.2), `transport/` (S3.2, S7, S8), `du/` (S5.1) and `ingress/` (S5.4, with the ZeroMQ channel broker of S6.10). Sensing algorithms do not live here. They stay in the host-free core so that the Aerial adapters can reuse them. [Port contract](../../docs/architecture/ABLATIONS.md)
