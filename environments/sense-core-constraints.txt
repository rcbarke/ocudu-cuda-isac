#
#   PIP_CONSTRAINT="$PWD/environments/sense-core-constraints.txt" make core-env            # export and binding
#   PIP_CONSTRAINT="$PWD/environments/sense-core-constraints.txt" make core-env-tensorrt   # the TensorRT wheel
#
# onnx, onnxruntime and pybind11 with what they pull in were installed from PyPI on linux x86_64
# and exercised there by the unit gate of the core: python tests/unit/test_sense_core.py.
# onnxruntime is used by that gate and by the integration driver to check an export on the CPU.
# No sensor imports it.
#
# tensorrt-cu13 is the release that the DGX Spark spark-ecf8 accepted on 2026-11-22 (UTC), run
# s36-spark-ecf8-20261122T194723Z: 11.5.0.63, which that host also holds as a package installation,

# was 10.14.1.48.post1, the release that the pinned Aerial sample applications install for CUDA 13:

# headers of the same release come from `python scripts/native_core.py headers`. A host with a
# package installation of TensorRT, or with TENSORRT_ROOT, needs no wheel. Whether a TensorRT
# builds and runs an engine on a host is what checkpoint D0 records, not this file:
# `python scripts/native_core.py probe` writes the version it accepted, with its origin, into
# sense-probe.json. Change this pin with the run that shows another version accepted.
