# Data and episodes

Keep the small executable contract fixture in `configs/`. Store generated arrays under ignored `data/episodes/` and downloaded public measurements under `data/external/`. Commit small [manifests](manifests/README.md) containing hashes, acquisition details, license/access information and experiment split. Use immutable opaque episode IDs when joining runtime observations to offline truth. `make episode-pair` and `make episode-set` write `channel-episode/v1` entries and `channel-episode-set/v1` sets into a new directory under `data/episodes/`. Each carries its own manifest with every hash, the scene, the solver flags, the seed, the axes and the split. [Episode entry and set](../docs/interfaces/EPISODE.md)
