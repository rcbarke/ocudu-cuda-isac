# Experiment definitions

[Demo](demo/PROTOCOL.md) defines the single-Spark experiment used for the first integrated showing. [Conference](conference/MATRIX.md) defines paired ablation families and load sweeps. They share the [evaluation protocol](../docs/research/EVALUATION.md). `splits/`, `aerial/` and `ota/` arrive with S5.4, S11 and S11.3. Every definition names one entry per [ablation axis](../docs/architecture/ABLATIONS.md). Only the fixture configuration in `configs/` executes in this release.
