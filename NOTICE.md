# Attribution and distribution

This repository contains contribution-specific interfaces, test fixtures and development documentation. The three Git dependencies retain their own license and notice files. Review these files at the pinned revisions when distributing a build, particularly any modified OCUDU component. Paper datasets, model weights, software and manuscripts may have distinct terms. Record the source, revision and applicable terms for each external artifact used. No third-party paper PDF, raw field capture, model weight or upstream code tree is embedded in this initial distribution. A public release of original project code requires a license selected by its rights holders.
