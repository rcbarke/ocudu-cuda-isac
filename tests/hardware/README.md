# Hardware tests

Run S1 and S2 with the pinned checkout and log hardware/driver versions. Use the [Spark runbook](../../docs/demo/SPARK.md). For S3/S4 add MPS attachment, queue saturation, native callback ownership and real CRC/byte comparisons. For distributed runs verify negotiated CX7 speed, clock uncertainty, checksum and consumer credits. For GB300 record isolated GI UUIDs, supported profiles, chosen bridge and a same-host shared-GPU control. For S5.4 take the executed split from the application log. For S10 and S11 record the Aerial revisions, the emulator or radio placement and whether slot timing was valid. Record absent hardware as pending in the sprint checklist; hosted CPU CI only covers the portable contracts.
